## 接入 i18n（中文 / English）

- 装了 `@nuxtjs/i18n@10.6.0`。**包名是 `@nuxtjs/i18n`，不存在 `@nuxt/i18n`。**
- 方案：`strategy: 'no_prefix'`（URL 完全不变，对现有 SSG / nginx 零风险）+ `defaultLocale: 'zh-CN'`，
  翻译文件放 `i18n/locales/zh-CN.json` / `en.json`（`restructureDir` 默认 `i18n`、`langDir` 默认 `locales`；
  用了 `langDir` 时每个 locale 必须显式写 `file`，否则报错）。
- **不做语言切换按钮**（用户明确不要）：交给 `detectBrowserLanguage` 按浏览器语言偏好自动选；
  `useCookie: false` —— 没有按钮就不该把检测结果存下来，否则用户以后改浏览器语言会被旧 cookie 压住且无从改回。
  ⚠️ 静态部署下「按 Accept-Language 出不同 HTML」做不到：构建期只渲染一份默认语言 HTML，语言在客户端按
  `navigator.languages` 切。
- 全站 UI 文案抽到翻译文件，命名空间：`site / common / home / search / typeFilter / actions / theme /
  card / chart / heatmap / weekday / notice`。组件里用 `$t()`，composable 里用 `useI18n().t()`。
  涉及文件：`pages/index.vue`、`pages/[...slug].vue`、`Search.vue`、`TypeDropdown.vue`、`FloatingMenu.vue`、
  `BackToTop.vue`、`BlogCard.vue`、`SpinCircle.vue`、`Dialog.client.vue`、`UpdateHeatmap.client.vue`、
  `ThemeToggle.vue`、`useShareNote.ts`。
- `utils/site.ts` 删除 → `composables/useSiteMeta.ts`：`pageTitle` 要跟着语言变，
  纯 util 拿不到 `useI18n()`，必须做成 composable。
- `<html lang>` 不会自动设：`app.vue` 里 `useHead({ htmlAttrs: { lang } })`（取 `localeProperties.value.language`）。
  刻意不用 `useLocaleHead()` —— no_prefix 下它的 canonical / hreflang 只指向页面自己，还刷 baseUrl 警告。
- 热力图周标签本地化：`utils/heatmap.ts` 不再导出中文 `WEEKDAY_LABELS`，
  改为 `WEEKDAY_KEYS`（mon..sun）+ `DEFAULT_WEEKDAY_LABELS` 兜底，
  `weekdayLabels` 作为 `buildHeatmapGrid` 的入参；组件里行下标改用 `grid.yLabels.indexOf()`。
