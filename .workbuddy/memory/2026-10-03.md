## FloatingMenu 「消失」排查 + 分享功能拆分

### Bug：组件整块不渲染
- 现象：`FloatingMenu.vue` 完全不出现在文档页。
- 根因：重写组件时漏掉了 `const { canGoBack, goBack } = useNavigationStack()`，
  模板里的 `v-if="canGoBack"` 取到 `undefined`（falsy）→ 永远不渲染。
  Vue dev 只给一句 warn（`Property "canGoBack" was accessed during render but is not defined on instance`），
  不报错，所以很容易漏。**教训：`v-if` 用的绑定必须在 `<script setup>` 里有声明，删代码时别把声明一起删了。**
- 修复：把那一行加回来。

- `app/composables/useNotice.ts`：轻提示状态（`useState('notice-message')` + 2s 自动消失）。
- `app/components/Notice.vue`：提示 UI（fixed 底部居中），挂在 `app.vue` 里全站一份。

## 暗色主题 + 明暗切换按钮

### 调色板（同色相 · 翻明度 · 降纯度）
- 亮色关系：暖黄画布 `#FEFEF1`(H60) → 冷紫互补面 `#F0F0FE`(H240) → 橄榄邻近按钮 `#D6D8B7`(H64) → 暖褐搜索 `#D8C9B6`(H33)。
- 暗色沿用同一套关系：`#1B1A13`(H53) / `#24242F`(H240) / `#34372A`(H70) / `#3B332A`(H32)，
  文字 `#E3E3EA`、标题 `#FDFDF7`、链接 `#8FAAD0→#8FAAF0`、行内代码 `#F0A0BC`。
- 三处定义（改色要一起改）：`main.scss` 的 `$color-dark-*`、`main.css` 的 `@theme --color-dark-*`、
  `main.css` 里给组件 scoped 样式用的语义层 `:root/.dark --ui-*`。

### 机制
- 类挂在 `<html>`：`@custom-variant dark (&:where(.dark, .dark *))`；Nuxt Content 的 shiki 双主题
  生成的也是 `html.dark .shiki span { color: var(--shiki-dark) }`，所以类名只能用 `dark`。
- 首屏防闪：`nuxt.config.ts` 的 `app.head.script`（内联，在 `<link>` 之前）读 localStorage/prefers-color-scheme 加类；
  键名 `blog-theme` 与 `composables/useTheme.ts` 的常量一致。
- 切换按钮 `components/ThemeToggle.vue`：全局挂在 `app.vue`，`fixed` 在容器右侧、与 FloatingMenu 同一行
  （都取 `p-4` = 1rem，按钮尺寸也一致：48×32）。

### 坑（这次踩到的）
- **Vue scoped `:global(...) &` 会连后面的选择器一起丢**：`:global(body:has(.x)) .theme-toggle` 编译成
  `body:has(.x){...}`（看了 `@vue/compiler-sfc` 的 `selector.replaceWith(n.nodes[0])`）。
  要按页面调位置就用 CSS 变量：`main.css` 里 `body:has(.filter-bar){--floating-top:4.75rem}`，
  组件写 `inset: var(--floating-top) 0 auto 0`。
- 首页 `.filter-bar` 是 `z-50` 的 fixed 层，浮动按钮 z-index 必须更高（用 55），否则被它的 backdrop-filter 糊掉看不见。
- Tailwind v4 会裁剪没被工具类引用的 `@theme` 变量（`--color-dark-background` 就没进 :root），
  所以组件 scoped 样式一律用 `--ui-*` 语义变量，不要 `var(--color-dark-*)`。
- 仓库里有 on-save 的格式化/清理（会把 `catch {}` 里的注释抹掉）→ 别靠注释过 `no-empty`，
  写真实语句（这里是 `console.warn`）。

### 验证
- curl 编译产物：`@custom-variant` 生成 `.dark\:bg-dark-search:where(.dark, .dark *)` ✅，
  main.scss 编译出 `html.dark{#e3e3ea/#1b1a13}`、`.dark .markdown-body` ✅。
- CDP 实测：`/` 上按钮 `top:76px`（在筛选条下面，和搜索框右边缘对齐 686）、

## 内容路径塌陷："点 opengel 哪篇都跳第一篇"

### 现象
`/cpp/opengel/*` 里点任意一篇，都打开 `三角形绘制`（该路径的第一条）。

### 根因（两层，缺一不可）
1. **@nuxt/content 的 path 生成把中文整段删掉**。
   `dist/module.mjs`：`const { pathMeta = {} } = nuxtOptions?.content?.build` →
   `generatePath` = `path.split('/').map(part => slugify(refineUrlPart(part), slugifyOptions))`，
   默认 `slugifyOptions = { lower: true }`。
   `slugify@1.6.9` 的默认 `remove` 正则 `/[^\w\s$*_+~.()'"!\-:@]+/g` 里 `\w` 只含 `[A-Za-z0-9_]`，
   **中文不属于 `\w` → 全被删**；另外 charMap 里 `$` → `dollar`，`+` 未映射所以被保留。
   于是大量文件塌成同一 path：opengel 13 篇 → `/cpp/opengel`；
   `C++的学习笔记`/`C++编译器思考`/`优雅和正确的使用C++的注释` → `/cpp/c++`；
   `C#的多线程`/`c#的流传输文件…` → `/csharp/c`；`Avalonia/合成渲染器` 等 5 篇 → `/csharp/avalonia`；
   `Vue学习笔记` 等一堆 → `/vue/vue`；`面试笔记.md` → `/`。
   `.path(route.path).first()` 永远命中第一条，这就是"总跳第一篇"。
2. **`route.path` 是 percent-encoded，库里存的是解码原文**。
   vue-router 的 `route.path` 保留编码（中文 → `%E4%B8%89…`，`+` → `%2B`），
   而 content 库 `path` 是解码后的原文；纯 ASCII 时两者恰好相等，所以只有中文/特殊字符 404。
   dev 日志里请求行就是 `/cpp/opengel/%E4%B8%89%E8%A7%A6...` 这种形式，可佐证。

### 修复
- `nuxt.config.ts` → `content.build.pathMeta.slugifyOptions.remove` 把 CJK 加回白名单：
  `/[^\w\s$*_+~.()'"!\-:@\u4e00-\u9fff]+/g`（顺手去掉 URL 里真会出事的 `# ? % &` 空格等）。
- `app/pages/[...slug].vue` → 查询前 `decodeURIComponent(route.path)`（用 `contentPath` 变量，try/catch 兜底）。
- 两处配合后：`/cpp/opengel/三角形绘制`、`/cpp/c++的学习笔记`、`/csharp/c的多线程`（title 仍是 `C#的多线程`）
  `/vue/dollarrouter和dollarroute的区别`（title 仍是 `$router和$route的区别`）全部可用。

### 验证
- sqlite（`.data/content/contents.sqlite`，node `--experimental-sqlite` 直读）：
  134 条记录 **重复 path = 0**；opengel 13 条路径各自唯一。
- HTTP：含中文/`+`/`$` 的 URL 由 404 → **200 且标题正确**；
  CDP 用应用 router 连续 `push` 三角形绘制→纹理→摄像机→Axios，title/h1 逐个正确 → SPA 跳转会重新取数。

### 结论：不需要改文件名
`+` 在真实链接里保持字面量、能正常匹配（只有我手工 `%2B` 编码才不匹配）；
`#` 被 slugify 清掉所以不进 URL。**文件名不必改**，`C#→c`、`$→dollar` 只是 URL 可读性略差。
