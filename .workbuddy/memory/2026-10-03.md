# 2026-10-03

## 页面 meta（name/description）取自笔记

用户需求：用「defineMeta」设置页面名称等信息，让页面显示笔记 title。

- **没有 `defineMeta` 这个 API**（`@nuxt/content` 里也没有），本项目里能用的只有 `definePageMeta`。
  它是 Nuxt 的**编译期宏**，参数只能是静态字面量，所以那里仍然只能放 `layout`；笔记的 title 是
  `await queryCollection()` 拿到的运行时值，只能交给 `useSeoMeta`（getter 形式，可响应式更新）。
- 新增 `app/utils/site.ts`：`SITE_NAME` / `SITE_DESCRIPTION` / `pageTitle(title)`（拼「标题 · 站点名」，
  标题为空时只返回站点名）。改站点名只改这里。
- `app/pages/[...slug].vue`：`useSeoMeta({ title, description, ogTitle, ogDescription, ogType:'article' })`；
  另外补了个可见标题——正文第一个元素节点不是 `h1` 时就渲染 `<h1 class="doc-title">`，
  因为不少笔记（`Vue/axios.md`、`Vue/Pinia.md`、`Vue/Nuxt/Nuxt4.md`）正文里压根没有 h1，页面会「没有名字」。
  判重用 `body.value` 里找第一个 `Array.isArray(node) && typeof node[0]==='string'` 的节点。
- `app/pages/index.vue`：`title = '全部笔记 · Blog'`，description 用 `SITE_DESCRIPTION`。

### 实测（SSR HTML + 无头 Chrome）
- `/` → `全部笔记 · Blog`；`/about` → `About Content Version 3 · Blog`；
  `/vue/axios` → `Axios · Blog` + 补出 `<h1 class="doc-title">Axios</h1>`（全页 h1 只有一个）；
  `/vue/nuxt/nuxt4` → `Nuxt4 · Blog` + 补 h1；`/vue/vue3` → `1. Vue3简介`（正文自带 h1，不重复）。
- 客户端跳转（点卡片）title / og:title / og:type 都跟着换；跳回首页 og 标签会被清掉（unhead 按组件作用域回收）。
- 文档路径是**小写**的：`content/Vue/axios.md` → `/vue/axios`（`/Vue/axios` 会 404）。

### nuxt/content 的字段真相（从 `sql_dump.txt` 确认）
- `title`：frontmatter 没有时，**用文件名兜底**（`Vue/axios.md` → `Axios`）。
- `description`：frontmatter 没有时，**用首段正文兜底**（`about.md` → `Back home`）；正文首块是代码块时为空。
- 表格里没有 `type`/`date` 列（type 由路径推导，见上一日的记录）。
