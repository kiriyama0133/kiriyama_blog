## FloatingMenu 「消失」排查 + 分享功能拆分

### Bug：组件整块不渲染
- 现象：`FloatingMenu.vue` 完全不出现在文档页。
- 根因：重写组件时漏掉了 `const { canGoBack, goBack } = useNavigationStack()`，
  模板里的 `v-if="canGoBack"` 取到 `undefined`（falsy）→ 永远不渲染。
  Vue dev 只给一句 warn（`Property "canGoBack" was accessed during render but is not defined on instance`），
  不报错，所以很容易漏。**教训：`v-if` 用的绑定必须在 `<script setup>` 里有声明，删代码时别把声明一起删了。**
- 修复：把那一行加回来。

### 拆分（按用户要求：组件不许冗杂）
- `app/composables/useShareNote.ts`：分享收口。读 `reader` store 的 `title/description/path`
  → `pageTitle()` + `window.location.origin` 拼 URL → `useShare` 调系统面板；
  取消（AbortError）静默；不支持或报错 → `useClipboard` 复制链接兜底 → `useNotice().notify()`。
- `app/composables/useNotice.ts`：轻提示状态（`useState('notice-message')` + 2s 自动消失）。
- `app/components/Notice.vue`：提示 UI（fixed 底部居中），挂在 `app.vue` 里全站一份。
- `app/components/FloatingMenu.vue`：只剩两个按钮 + mask 图标样式。
- `app/stores/reader.ts` / `app/pages/[...slug].vue`：store 增加 `description`，slug 页写进去。

- headless 下 `notifier.share=true`，点分享不弹提示（走成功/AbortError 分支），符合预期。

## 暗色主题 + 明暗切换按钮

### 调色板（同色相 · 翻明度 · 降纯度）
- 亮色关系：暖黄画布 `#FEFEF1`(H60) → 冷紫互补面 `#F0F0FE`(H240) → 橄榄邻近按钮 `#D6D8B7`(H64) → 暖褐搜索 `#D8C9B6`(H33)。
- 暗色沿用同一套关系：`#1B1A13`(H53) / `#24242F`(H240) / `#34372A`(H70) / `#3B332A`(H32)，
  文字 `#E3E3EA`、标题 `#FDFDF7`、链接 `#8FAAD0→#8FAAF0`、行内代码 `#F0A0BC`。
- 三处定义（改色要一起改）：`main.scss` 的 `$color-dark-*`、`main.css` 的 `@theme --color-dark-*`、
  `main.css` 里给组件 scoped 样式用的语义层 `:root/.dark --ui-*`。

### 机制
- 类挂在 `<html>`：`@custom-variant dark (&:where(.dark, .dark *))`；Nuxt Content 的 shiki 双主题
  生成的也是 `html.dark .shiki span { color: var(--shiki-dark) }`，所以类名只能用 `dark`。
- 首屏防闪：`nuxt.config.ts` 的 `app.head.script`（内联，在 `<link>` 之前）读 localStorage/prefers-color-scheme 加类；
  键名 `blog-theme` 与 `composables/useTheme.ts` 的常量一致。
- 切换按钮 `components/ThemeToggle.vue`：全局挂在 `app.vue`，`fixed` 在容器右侧、与 FloatingMenu 同一行
  （都取 `p-4` = 1rem，按钮尺寸也一致：48×32）。

### 坑（这次踩到的）
- **Vue scoped `:global(...) &` 会连后面的选择器一起丢**：`:global(body:has(.x)) .theme-toggle` 编译成
  `body:has(.x){...}`（看了 `@vue/compiler-sfc` 的 `selector.replaceWith(n.nodes[0])`）。
  要按页面调位置就用 CSS 变量：`main.css` 里 `body:has(.filter-bar){--floating-top:4.75rem}`，
  组件写 `inset: var(--floating-top) 0 auto 0`。
- 首页 `.filter-bar` 是 `z-50` 的 fixed 层，浮动按钮 z-index 必须更高（用 55），否则被它的 backdrop-filter 糊掉看不见。
- Tailwind v4 会裁剪没被工具类引用的 `@theme` 变量（`--color-dark-background` 就没进 :root），
  所以组件 scoped 样式一律用 `--ui-*` 语义变量，不要 `var(--color-dark-*)`。
- 仓库里有 on-save 的格式化/清理（会把 `catch {}` 里的注释抹掉）→ 别靠注释过 `no-empty`，
  写真实语句（这里是 `console.warn`）。
